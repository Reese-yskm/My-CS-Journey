# 第 2 章 连通和遍历

本章默认讨论**简单无向图**。核心问题只有三个：

1. 图中的两个顶点能不能互相到达？
2. 图中哪些顶点或边一删就会让网络断开？
3. 两个顶点之间最少经过多少条边？

它们分别对应 DFS、基于 DFS 的割点/割边算法，以及 BFS。

---

## 2.1 连通和 DFS

### 1. 路线、迹与路径

图里的“走法”需要先说清楚。设路线从顶点 `v0` 出发，到 `vl` 结束：

```text
v0, e1, v1, e2, v2, ..., el, vl
```

其中每条边 `ei` 的两个端点正好是 `v(i-1)` 和 `vi`。

- **起点 / 终点**：`v0` 和 `vl`。
- **路线长度**：经过边的数量 `l`。
- **平凡路线**：长度为 `0`，只含一个顶点。
- **闭路线**：起点和终点相同。
- **迹（trail）**：路线中不重复使用边。
- **路径（path）**：路线中不重复出现顶点。路径中除了起点和终点外的顶点称为内点。

例如：

```text
0 - 1 - 2 - 0 - 3
```

若按 `0, 1, 2, 0, 3` 走，边没有重复，但顶点 `0` 重复，所以它是迹，不是路径。

对无向图，路线可以倒着走；因此从 `u` 到 `v` 有路线，就一定也能从 `v` 回到 `u`。

### 2. 连通、连通图与连通分支

若顶点 `u` 与 `v` 之间存在一条路径，就说 `u` 和 `v` **连通**，记为 `u ~ v`。

连通关系是顶点集上的等价关系：

- 自反：`u ~ u`，因为顶点 `u` 自己构成平凡路线。
- 对称：`u ~ v` 时，倒着走原路径即可得到 `v ~ u`。
- 传递：`u ~ v` 且 `v ~ w` 时，把两条路线接起来并去掉其中的重复部分，可得到 `u ~ w`。

因此，一个图的顶点会被自然地分成若干个互不重叠的组：同一组内任意两点连通，不同组之间没有路径。

若图中任意两个顶点都连通，则图是**连通图**；否则是**不连通图**。

一个连通分量（教材称**连通分支**）是极大的连通点集。若 `V1, V2, ..., Vk` 是图中所有连通分量的顶点集，那么：

```text
V = V1 ∪ V2 ∪ ... ∪ Vk
```

并且它们两两不相交。每个点导出子图 `G[Vi]` 都是一个连通分支。孤立顶点也算一个平凡连通分支。

例子：

```text
0 - 1 - 2      3 - 4      5
```

这个图有 3 个连通分支：`{0, 1, 2}`、`{3, 4}`、`{5}`。

### 3. DFS：从一个点走遍它所在的连通分支

DFS 是深度优先搜索（Depth-First Search）。它从一个起点出发，看到一个未访问邻点就立刻继续向下走；走不动时再退回到上一个岔路口。

它的关键状态只有一个：

```text
visited[u] = True / False
```

含义是顶点 `u` 是否已经访问过。必须在刚进入 `u` 时立刻标记，否则图中有环时会在两个点之间无限递归。

#### 教材中的 DFS 过程

输入是一张图 `G = (V, E)` 和起点 `u`，所有顶点初始均未访问：

```text
DFS(u):
    标记 u 已访问
    对 u 的每个邻点 v：
        若 v 未访问：
            DFS(v)
```

“深度优先”只描述搜索策略，不保证访问顺序唯一。邻接点的枚举顺序不同，得到的 DFS 访问顺序可能不同；但访问到的连通分支是同一个。

#### 为什么 DFS 能访问所有可达顶点

从 `u` 出发，假设有顶点 `x` 可以到达。取一条 `u` 到 `x` 的路径。

- DFS 一定会访问路径的起点 `u`。
- 每当 DFS 访问路径上的某个顶点，它都会检查这条路径通向下一个顶点的边。
- 下一个顶点若尚未访问，就会被递归访问；若已访问，更不需要重复处理。

所以路径上的每个顶点最终都会被访问，特别是 `x`。因此：**从 `u` 运行 DFS，恰好访问 `u` 所在连通分支的全部顶点。**

#### 邻接表与建图

下面统一用邻接表表示无向图。即使某个点没有边，也保留它的空列表，这样不会漏掉孤立点。

```python
def build_undirected_graph(n, edges):
    """把边集转成邻接表，顶点编号为 0 到 n - 1。"""
    graph = [[] for _ in range(n)]

    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)

    return graph
```

例如：

```python
graph = build_undirected_graph(
    6,
    [(0, 1), (1, 2), (3, 4)],
)

# graph == [[1], [0, 2], [1], [4], [3], []]
```

#### Python：判断两个顶点是否连通

```python
def has_path(graph, source, target):
    """返回 source 是否能到达 target。"""
    visited = [False] * len(graph)

    def dfs(u):
        # 当前递归调用正式接管顶点 u，先标记防止环造成重复搜索。
        visited[u] = True

        # 找到目标后直接向上返回 True。
        if u == target:
            return True

        for v in graph[u]:
            if not visited[v] and dfs(v):
                return True

        # u 的所有可走分支都试过，仍未到达 target。
        return False

    return dfs(source)
```

这里的 `dfs(v)` 会返回布尔值。若某条分支已经找到目标，`return True` 会一层层传回最外面；这是“判断可达”常用的早停写法。

#### Python：求所有连通分支

```python
def connected_components(graph):
    """返回图的所有连通分支，每个分支是一个顶点列表。"""
    n = len(graph)
    visited = [False] * n
    components = []

    def dfs(u, component):
        visited[u] = True
        component.append(u)

        for v in graph[u]:
            if not visited[v]:
                dfs(v, component)

    # 一次 DFS 只会覆盖一个分支，因此外层必须扫描全部顶点。
    for start in range(n):
        if visited[start]:
            continue

        component = []
        dfs(start, component)
        components.append(component)

    return components
```

对上面的 `graph`，结果可为：

```python
[[0, 1, 2], [3, 4], [5]]
```

#### DFS 的复杂度

设图有 `n` 个顶点、`m` 条边。

- 邻接表：每个顶点最多访问一次；无向边最多从两个端点各检查一次，因此时间复杂度为 `O(n + m)`。
- 额外空间：`visited` 与最坏情况下的递归栈均为 `O(n)`。
- 邻接矩阵：访问一个顶点时要扫描一整行，整体为 `O(n^2)`。这并不代表不能直接 DFS 邻接矩阵；LeetCode 547 就适合直接这样写。

Python 的递归深度有限。若图可能是一条很长的链，工程上可改成显式栈；算法思想不变。

```python
def dfs_with_stack(graph, start):
    """非递归 DFS，返回从 start 可达的顶点集合。"""
    visited = [False] * len(graph)
    stack = [start]
    visited[start] = True

    while stack:
        u = stack.pop()

        for v in graph[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)

    return visited
```

## 2.2 割点和割边

连通不代表稳固。有些网络删除一个顶点或一条边后，会分裂成更多部分；这些就是图的脆弱位置。

### 1. 割点

对任意图 `G` 和顶点 `u`，删除 `u` 以及所有与 `u` 关联的边，得到图 `G - u`。

若 `G - u` 的连通分支数大于 `G` 的连通分支数，则 `u` 是 **割点**（也叫关节点）。

在连通图中，定义可简化为：删除 `u` 后图不连通，则 `u` 是割点。

直观上，割点是“唯一中转站”。例如链：

```text
0 - 1 - 2
```

顶点 `1` 是割点；删掉它，`0` 与 `2` 被分开。

教材给出等价刻画：在连通图中，`u` 是割点，当且仅当存在两个不同于 `u` 的顶点 `x`、`y`，使得从 `x` 到 `y` 的每一条路径都经过 `u`。

这句话和定义是同一件事：删除 `u` 后 `x`、`y` 不再连通，等价于原图里所有 `x-y` 路都被 `u` 卡住。

### 2. 割边

对边 `e`，删除它得到 `G - e`。若删除后连通分支数增加，`e` 是 **割边**，也称桥。

在连通图中，`e` 是割边，当且仅当存在两个顶点 `x`、`y`，使得每条 `x-y` 路径都经过 `e`。

判断直觉：一条边位于环上时，不可能是割边，因为断掉它仍能沿环绕过去；一条边不在任何环上时，通常就是桥。

```text
0 - 1 - 2 - 3
    \_______/
```

其中 `1 - 2 - 3` 若构成环，那么环内的边都不是桥；从 `0` 连到 `1` 的边则是桥。

### 3. 为什么普通 DFS 还不够

普通 DFS 能告诉我们某点是否可达，却不能仅凭“DFS 树中的父子关系”判断割点。

例如 `u` 在 DFS 树中有孩子 `v`，但 `v` 的子树也许能通过一条非树边绕回 `u` 的祖先。此时删除 `u` 后，`v` 的子树仍能从那条备用通道回到外部，`u` 不是割点。

因此需要额外记录：**一个 DFS 子树最早能绕回到哪一个祖先。**

### 4. DFS 树、回边与四个属性

从一个根运行 DFS，第一次访问新顶点所经过的边组成 DFS 树。

- **树边**：第一次发现新顶点的边。
- **回边（back edge）**：从某顶点或其后代连向某祖先的非树边。

教材的 DFSCV 算法为每个顶点维护：

| 属性 | 含义 |
| --- | --- |
| `d[u]` | `u` 第几个被访问，叫发现时间 |
| `parent[u]` | 在 DFS 树中谁发现了 `u`；根为 `None` |
| `children[u]` | `u` 在 DFS 树中的孩子数 |
| `low[u]` | 从 `u` 的子树出发，走若干树边后最多走一条回边，最早能回到的祖先的发现时间 |
| `is_cut[u]` | `u` 是否被判为割点 |

`low[u]` 不是最短距离。它的意思是：“`u` 这棵子树有没有绕开父亲、回到更早祖先的备用通道？”

初始化时，刚访问 `u`：

```text
d[u] = low[u] = 当前时间
```

之后：

- 从孩子 `v` 返回时：`low[u] = min(low[u], low[v])`。
- 遇到一条指向祖先 `v` 的回边时：`low[u] = min(low[u], d[v])`。

### 5. 割点判定

设 `v` 是 `u` 的 DFS 树孩子。

#### 非根顶点

若：

```text
low[v] >= d[u]
```

则 `u` 是割点。

因为 `v` 的子树最早只能回到 `u`，却无法回到 `u` 的祖先。删掉 `u` 后，这棵子树就与外部断开。

注意是 `>=`，不是 `>`：即使子树能回到 `u` 本人，只要到不了 `u` 的祖先，删除 `u` 后它仍然出不去。

#### 根顶点

根没有父亲，不能套上面的式子。根是割点，当且仅当它在 DFS 树中至少有两个孩子：

```text
children[root] >= 2
```

这两个孩子子树之间没有树边相连；若有边，第二个孩子在 DFS 时本会通过第一个孩子子树被访问，不会仍是根的独立孩子。

### 6. 割边判定

同样设 `v` 是 `u` 的 DFS 树孩子。若：

```text
low[v] > d[u]
```

则树边 `(u, v)` 是割边。

这里必须是严格大于。若 `low[v] == d[u]`，说明 `v` 的子树至少能用回边回到 `u`，`(u, v)` 与那条回边及树路径构成环，删掉 `(u, v)` 仍能绕行。

### 7. 教材 DFSCV 算法

教材算法从一个连通图的根 `u` 开始，找全部割点。下面是等价的过程写法：

```text
DFSCV(u):
    time += 1
    d[u] = low[u] = time
    标记 u 已访问

    对 u 的每个邻点 v：
        若 v 未访问：
            parent[v] = u
            children[u] += 1
            DFSCV(v)
            low[u] = min(low[u], low[v])

            若 u 不是根且 low[v] >= d[u]：
                u 是割点
            若 u 是根且 children[u] >= 2：
                u 是割点

        否则若 v 不是 parent[u]：
            low[u] = min(low[u], d[v])
```

最后的“`v` 不是父亲”非常重要：无向边会从两个端点各看到一次。返回父亲的那条树边不是回边，不能拿来更新 `low`。

若图不连通，像求连通分支一样，外层扫描每个未访问顶点，对每个新分支的根运行一次 DFSCV。

### 8. Python：同时找割点和割边

下面代码是教材 DFSCV 的 Python 版，并顺手加入了割边判定。

```python
def find_cut_vertices_and_bridges(graph):
    """
    graph: 简单无向图的邻接表。
    返回: (割点集合, 割边列表)。
    """
    n = len(graph)

    # discovery[u] == -1 表示 u 尚未被 DFS 访问。
    discovery = [-1] * n
    low = [-1] * n
    parent = [-1] * n
    cut_vertices = set()
    bridges = []
    time = 0

    def dfs(u):
        nonlocal time

        # 第一次进入 u，记录它的发现时间。
        discovery[u] = time
        low[u] = time
        time += 1

        # 只有根节点需要用孩子数量进行割点判定。
        child_count = 0

        for v in graph[u]:
            if discovery[v] == -1:
                # (u, v) 是树边，u 是 v 的 DFS 父亲。
                parent[v] = u
                child_count += 1
                dfs(v)

                # v 的整棵子树能回到多早，会影响 u 自己的 low 值。
                low[u] = min(low[u], low[v])

                # 非根 u：v 子树无法绕回 u 的祖先，删 u 后会断开。
                if parent[u] != -1 and low[v] >= discovery[u]:
                    cut_vertices.add(u)

                # v 子树连 u 本人都回不去，(u, v) 是唯一通道。
                if low[v] > discovery[u]:
                    bridges.append((u, v))

            elif v != parent[u]:
                # (u, v) 是连向祖先的回边，用祖先的发现时间更新 low[u]。
                low[u] = min(low[u], discovery[v])

        # 根节点至少有两个 DFS 孩子时才是割点。
        if parent[u] == -1 and child_count >= 2:
            cut_vertices.add(u)

    # 兼容不连通图：每个连通分支各做一次 DFS。
    for start in range(n):
        if discovery[start] == -1:
            dfs(start)

    return cut_vertices, bridges
```

使用例子：

```python
graph = build_undirected_graph(
    6,
    [(0, 1), (1, 2), (2, 0), (1, 3), (3, 4), (4, 5), (5, 3)],
)

cut_vertices, bridges = find_cut_vertices_and_bridges(graph)

# cut_vertices == {1, 3}
# bridges 中包含 (1, 3)
```

`0, 1, 2` 形成一个环，`3, 4, 5` 也形成一个环；两部分只有边 `1 - 3` 相连，所以它是桥，`1` 和 `3` 都是割点。

#### 这段代码最容易错的地方

1. `low[u] = min(low[u], low[v])` 只在 `v` 是 DFS 孩子、递归返回后执行。
2. 对已访问邻点，更新用的是 `discovery[v]`，不是 `low[v]`。
3. 无向图必须跳过父边；否则父边会被误当作回边。
4. 根的判断与非根不同。
5. 上面写法针对简单图。若存在重边，需要给每条边编号，跳过“父边的编号”，不能只写 `v != parent[u]`。

#### 复杂度

每个顶点只第一次访问一次，每条边只做常数次处理，因此时间 `O(n + m)`，额外空间 `O(n)`。

## 2.3 距离和 BFS

### 1. 最短路与距离

在连通图中，`u` 到 `v` 的所有路径里，长度最小的一条称为 **u-v 最短路**。最短路长度称为两点之间的**距离**：

```text
dist(u, v)
```

因为本章是无权图，路径长度就是边数。例如：

```text
0 - 1 - 3
 \      /
   2 ---
```

从 `0` 到 `3` 的最短距离为 `2`，可走 `0 -> 1 -> 3` 或 `0 -> 2 -> 3`。

### 2. 距离矩阵与邻接矩阵幂

把图中任意两点的距离排成矩阵，就是距离矩阵。第 `i` 行第 `j` 列是：

```text
dist(vi, vj)
```

若 `A` 是图的邻接矩阵，则 `(A^k)[i][j]` 统计从 `vi` 到 `vj`、长度恰为 `k` 的路线数量。

所以若 `dist(vi, vj) = d`，那么：

```text
(A^1)[i][j], (A^2)[i][j], ..., (A^(d-1))[i][j] 都是 0
(A^d)[i][j] > 0
```

这说明矩阵幂与路径长度有关。但实际编程时，要求单源最短距离通常直接用 BFS，不需要真的去算矩阵幂。

### 3. 距离的性质

连通无向图的距离满足：

```text
dist(u, v) >= 0
dist(u, v) = 0 当且仅当 u = v
dist(u, v) = dist(v, u)
dist(u, w) <= dist(u, v) + dist(v, w)
```

最后一条是三角不等式：从 `u` 到 `w` 的最短路，不会比“先到 `v` 再到 `w`”更长。这些性质说明图上的距离是一种度量。

### 4. 离心率、中心、半径与直径

对顶点 `u`：

```text
ecc(u) = max(dist(u, v))，其中 v 遍历所有顶点
```

`ecc(u)` 称为 `u` 的**离心率**，即从 `u` 到全图最远顶点的距离。

- **中心点**：离心率最小的顶点。
- **半径**：最小离心率。

  ```text
  rad(G) = min(ecc(u))
  ```

- **边缘点**：离心率最大的顶点。
- **直径**：最大离心率，也等于图中两点距离的最大值。

  ```text
  diam(G) = max(ecc(u))
  ```

教材定理：

```text
rad(G) <= diam(G) <= 2 * rad(G)
```

理解右侧不等式：取一个中心 `c`，任意两点 `x`、`y` 都可以经 `c` 相连，长度至多是 `dist(x, c) + dist(c, y)`，而这两项均不超过半径。

### 5. BFS：按距离一层层扩张

BFS 是广度优先搜索（Breadth-First Search）。它不急着沿一条路走到底，而是先访问距离为 `0` 的起点，再访问距离为 `1` 的所有点，然后距离为 `2` 的所有点。

队列正好实现这种“先进先出”的层次顺序。

```text
起点 0：                第 0 层
起点的未访问邻点：      第 1 层
这些邻点的未访问邻点：  第 2 层
...
```

第一次发现一个顶点时，已经找到了到它的最短路；这就是 BFS 能求无权最短路的原因。

### 6. 教材中的 BFS 过程

教材对每个顶点维护：

- `visited[u]`：是否被访问。
- `d[u]`：起点到 `u` 的距离；初始为无穷大。
- `parent[u]`：谁首次发现了 `u`，可用于恢复最短路。
- 队列 `Q`：已发现但还没有展开邻点的顶点。

过程如下：

```text
BFS(u):
    标记 u 已访问
    d[u] = 0
    u 入队

    当队列非空：
        v 出队
        对 v 的每个邻点 w：
            若 w 未访问：
                标记 w 已访问
                parent[w] = v
                d[w] = d[v] + 1
                w 入队
```

顶点要在**入队时**标记已访问，而不是出队时。否则同一个顶点可能被多个前驱重复加入队列。

### 7. BFS 为什么得到最短距离

队列中顶点的距离非递减：距离为 `d` 的点会先于距离大于 `d` 的点出队。

当处理距离为 `d` 的顶点 `u` 时，所有首次发现的邻点 `v` 都被赋值为 `d + 1`。如果存在一条更短路径到 `v`，那么这条路径上的前一个顶点会更早出队，`v` 也应当更早被发现，矛盾。

因此 BFS 结束时：

```text
d[v] = dist(start, v)
```

并且从 `parent[v]` 一直回溯到起点，就得到一条最短路。所有 `parent` 边组成一棵 BFS 树。

### 8. Python：单源最短路与路径还原

```python
from collections import deque


def bfs_shortest_paths(graph, start):
    """
    返回两个列表：
    distance[v] 是 start 到 v 的最短距离；不可达为 -1。
    parent[v] 是 BFS 树中 v 的父亲；start 和不可达点为 -1。
    """
    n = len(graph)
    distance = [-1] * n
    parent = [-1] * n

    queue = deque([start])
    distance[start] = 0

    while queue:
        u = queue.popleft()

        for v in graph[u]:
            # distance[v] 不再是 -1，说明 v 以前已经入过队，
            # 那一次入队就是它的最短距离，不应重复处理。
            if distance[v] != -1:
                continue

            distance[v] = distance[u] + 1
            parent[v] = u
            queue.append(v)

    return distance, parent


def restore_path(parent, start, target):
    """根据 BFS 的 parent 数组还原 start 到 target 的一条最短路。"""
    if start == target:
        return [start]

    # target 没有父亲，说明它未被 BFS 发现，即不可达。
    if parent[target] == -1:
        return []

    path = []
    current = target

    # 沿父亲指针倒着回到 start。
    while current != -1:
        path.append(current)
        current = parent[current]

    path.reverse()
    return path
```

示例：

```python
graph = build_undirected_graph(
    6,
    [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)],
)

distance, parent = bfs_shortest_paths(graph, 0)

# distance == [0, 1, 1, 2, 3, 4]
# restore_path(parent, 0, 5) 可能为 [0, 1, 3, 4, 5]
```

执行前几步：

| 操作 | 队列 | 新确定的距离 |
| --- | --- | --- |
| 起点 0 入队 | `[0]` | `d[0] = 0` |
| 0 出队，发现 1、2 | `[1, 2]` | `d[1] = d[2] = 1` |
| 1 出队，发现 3 | `[2, 3]` | `d[3] = 2` |
| 2 出队 | `[3]` | 3 已访问，不重复入队 |
| 3 出队，发现 4 | `[4]` | `d[4] = 3` |

### 9. 单元测试：腐烂的橘子（LeetCode 994）

#### 简洁实现：多源 BFS + 分层计时

这题的队列存的是“当前已经腐烂、能够继续传播的橘子”。所有初始腐烂橘子同时入队，构成第 0 分钟；每完整处理一层，时间过去 1 分钟。

```python
from collections import deque


class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        rows = len(grid)
        cols = len(grid[0])
        queue = deque()
        fresh = 0

        # 所有初始腐烂橘子都是同时开始扩散的 BFS 起点。
        for row in range(rows):
            for col in range(cols):
                if grid[row][col] == 2:
                    queue.append((row, col))
                elif grid[row][col] == 1:
                    fresh += 1

        minutes = 0
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

        # fresh > 0 时才需要继续等待；一层队列就是一分钟。
        while queue and fresh > 0:
            for _ in range(len(queue)):
                row, col = queue.popleft()

                for dr, dc in directions:
                    next_row = row + dr
                    next_col = col + dc

                    if not (0 <= next_row < rows and 0 <= next_col < cols):
                        continue
                    if grid[next_row][next_col] != 1:
                        continue

                    # 直接改 grid 就同时完成“感染”和“标记访问”。
                    grid[next_row][next_col] = 2
                    fresh -= 1
                    queue.append((next_row, next_col))

            minutes += 1

        return minutes if fresh == 0 else -1
```

这版比带 `visited` 和每个状态携带 `t` 的版本更短，因为题目原来的 `grid` 已经能充当访问标记：`1` 表示尚未访问的新鲜橘子，改成 `2` 后便不会再次入队。

### 10. BFS 的复杂度与用途

邻接表中：

- 时间复杂度：`O(n + m)`。
- 额外空间：`O(n)`，来自距离、父亲、队列。

BFS 除了最短路，还能：

- 判断两点是否连通。
- 判断整个图是否连通。
- 求所有连通分支。
- 在网格中求最少移动步数。

但它只适用于每条边代价相同的情况。若边权不同，普通 BFS 不能保证最短距离；通常需要 Dijkstra 等算法。

### 11. 双向 BFS

教材把双向搜索作为拓展阅读。

若只关心 `u` 到 `v` 的最短路，可以同时：

- 从 `u` 向外 BFS；
- 从 `v` 向外 BFS；
- 两边访问集合相遇时停止。

直觉上，单向搜索要把半径为 `d` 的范围全展开；双向搜索把它分成两半，通常能少访问很多顶点。适合状态空间很大、起点终点明确的无权最短路问题。

## 本章代码使用前的检查

1. 题目是无向图还是有向图？本章割点与割边代码只针对无向图。
2. 图有多少顶点？建邻接表时要把孤立点保留下来。
3. 目标是可达性还是最短路？可达性用 DFS/BFS 均可；无权最短路优先 BFS。
4. 是否可能有环？只要可能有环，就必须维护访问标记。
5. 是否可能有重边？普通 `parent` 判断割点/割边时要额外小心。
6. 图是否可能不连通？求全图性质时要有外层循环启动多次 DFS/BFS。

## 本章小结

- **DFS**：沿一条分支走到底，解决可达性、连通性、连通分支，并构造 DFS 树。
- **DFSCV / low-link**：在 DFS 树上记录发现时间和回边信息，找出割点；同样可以找割边。
- **BFS**：按距离分层，第一次访问一个顶点时就确定了无权最短距离。

这一章的真正主线是：先用遍历把图“走出来”，再把遍历过程中获得的结构信息转成结论。
